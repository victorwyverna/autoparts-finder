# Autoparts Finder

Клиентское приложение для двухэтапного поиска автозапчастей: сначала по
артикулу выбирается производитель, затем отображаются аналоги и складские
предложения.

Сейчас в репозитории подготовлен базовый каркас приложения. Интеграция с API
и пользовательский сценарий поиска будут добавлены на следующем этапе.

## Стек

- React и Vite;
- Redux Toolkit и React Redux;
- Bootstrap;
- Vitest и React Testing Library;
- ESLint;
- JavaScript без TypeScript.

## Требования

- Node.js 22.12 или новее;
- npm 10 или новее.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминале.

## Команды

```bash
npm run dev          # локальный сервер разработки
npm test -- --run    # однократный запуск тестов
npm run lint         # проверка ESLint
npm run build        # production-сборка
```

## Структура

Проект следует Feature-Sliced Design и содержит только используемые сейчас
слои:

```text
src/
├── app/             # композиция приложения, провайдеры и глобальные стили
├── pages/           # страницы приложения
├── shared/lib/      # переиспользуемые технические утилиты
└── main.jsx         # браузерная точка входа
```

Слои `features`, `entities` и API-модули будут добавляться вместе с реальной
функциональностью, без пустых директорий и заготовок.

## Переменные окружения

`.env.example` содержит адрес API и демонстрационный ключ из публичной
документации. Переменные с префиксом `VITE_` попадают в браузерную сборку,
поэтому их нельзя использовать для хранения секретов.
